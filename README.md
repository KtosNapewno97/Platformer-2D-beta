# 2D Platformer – Pygame + Nuitka

========================================================================================================================================================================================

**2D Platformer** is a Python game built using **Pygame**, featuring procedurally generated worlds, AI-controlled enemies, collectible coins, particle effects, and smooth platforming mechanics.

---

## 🎮 Game Features

- Infinite world generation with platforms and obstacles
- AI-controlled enemies patrolling platforms
- Collectible coins on platforms
- Basic collision with walls and obstacles
- Restart with a "You Died!" message after losing a life

---

## ⚙️ Requirements

- Python 3.10+ (x64)
- Pygame 2.x
- Nuitka 1.x (for building EXE)
- Optional: PyOpenGL if planning to add 3D features
